# ⚡ Lumina Festival 2037 — Web Landing Page

[![Live Demo](https://img.shields.io/badge/DEMO-ONLINE-00f0ff?style=for-the-badge&logo=vercel&logoColor=black)](https://luminafestival2037.vercel.app/)

![Lumina Festival Banner](https://images.unsplash.com/photo-1516450360452-9312f5e86fc7?auto=format&fit=crop&w=1200&q=80)

Welcome to the official web repository for **Lumina Festival 2037**, an immersive digital landing page designed with a vibrant cyberpunk and neon aesthetic. Built using **React**, **Tailwind CSS**, and **Framer Motion**, this project showcases event schedules, an interactive digital promotional poster, a full menu for food & drinks with local COP pricing, and dynamic ticket purchasing sections.

---

## 🌐 Live Website

Check out the live application here:
👉 **[Lumina Festival 2037 Live Web App](https://luminafestival2037.vercel.app/)**

---

## ✨ Features

- 🛸 **Cyberpunk & Neon UI**: Futuristic design system with custom glowing effects, gradient animations, and smooth motion effects.
- 🎨 **Digital Poster Component (`FestivalPoster.jsx`)**: Custom Canva-style digital flyer with event details, real-time ticket call-to-action, and high-impact visual design.
- 🍔 **Interactive Gastronomy Zone (`Food.jsx`)**: Dynamic food, drinks, and snacks menu with category filtering, COP pricing, and responsive grid layouts.
- 🎟️ **Smooth Navigation & Routing**: Seamless internal anchor jumping across `#lineup`, `#attractions`, `#food`, and `#tickets` with full mobile menu support.
- 📱 **Fully Responsive**: Optimized for seamless viewing on desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

- **Framework**: React 18 / Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React / FontAwesome

## 🚀 Getting Started

Follow these steps to run the project locally on your machine:

### 1. Clone the repository
```bash
git clone https://github.com/your-username/lumina-festival-2037.git
cd lumina-festival-2037
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open `http://localhost:5173` in your browser to view the app.
